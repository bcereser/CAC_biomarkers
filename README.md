## Repository Contents

This repository contains the code and supporting files used for the computational analyses described in the dissertation, including:

- **DepMap analysis**
- **Gene Ontology (GO) visualisation scripts**
- **Computational validation of WGBS candidate genes using GSE236055**
- Supporting scripts used for data processing, statistical analysis and figure generation
